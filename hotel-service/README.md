# hotel-service

Каталог отелей и номеров, календарь резервирований, рекомендации и статистика. Сущности и миграции находятся в src/main. Интеграционные тесты проверяют календарь, конкурентные запросы и равномерный атомарный автоподбор. Выбор и резервирование координируются строкой reservation_guard.

Сборка, запуск, API и параметры описаны в [корневом README](../README.md).
