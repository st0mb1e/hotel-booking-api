# common

Общие транспортные контракты, проверки JWT и формат HTTP-ошибок. JPA-сущности остаются внутри бизнес-сервисов. Общая Servlet Security подключается явно из конфигурации соответствующего сервиса. Отдельный test-jar содержит RSA fixture для тестов трёх модулей и не включается в приложения.

Сборка, запуск, API и параметры описаны в [корневом README](../README.md).
