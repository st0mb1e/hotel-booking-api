# Проверка

JUnit-тесты запускаются без работающих приложений:

```sh
./mvnw clean verify
```

Проверяются API, роли, даты, повторные и параллельные запросы, тайм-ауты и компенсации. Форматирование проверяется при сборке, для исправления нужен `./mvnw spotless:apply`.

## HTTP-проверки

Нужно [запустить приложения](../README.md#запуск) с демоданными и выполнить:

```sh
python3 scripts/smoke-test.py
python3 scripts/load-test.py
python3 scripts/integration-test.py
```

- `smoke-test.py`: вход, основные запросы API, повтор брони и конкуренция за один номер.
- `load-test.py`: равномерный автоподбор при 32 параллельных запросах и конфликты при нехватке номеров.
- `integration-test.py`: потеря ответа Hotel и повтор освобождения после временного сбоя.

Скрипты создают тестовые записи. Настройка адресов для других портов описана в [инструкции запуска](running.md#другие-порты).
