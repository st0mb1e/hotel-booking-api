# 3. JWT и доступ

Booking подписывает JWT алгоритмом RS256. Gateway и Hotel получают публичный ключ. Пользовательский токен действует час, роли проверяются через `@PreAuthorize`.

У служебного токена отдельная аудитория `hotel-service` и scope `rooms:write`. Это позволяет закрыть резервирование и освобождение для пользовательских токенов. Внутренние маршруты заблокированы в Gateway.

При работе с бронью проверяется её владелец. Пароли хранятся как BCrypt-хеши. Отключённый пользователь не может войти или создать бронь.
