# 4. Вызовы Hotel и обработка сбоев

По умолчанию на полный ответ Hotel отводится 2 с. Для сетевых ошибок и ответов 429/5xx выполняется до трёх попыток с растущей задержкой. Остальные 4xx не повторяются. Настройки находятся в `HotelClientProperties`.

Для резервирования и компенсаций используются отдельные Circuit Breaker. Сбой создания брони не должен блокировать освобождение уже занятого номера.

Тайм-аут учитывает чтение тела ответа. Этот случай проверяет `HttpHotelClientTest`. Gateway возвращает единый `ApiError` и сохраняет `X-Request-Id` на ошибках.
