# booking-service

Пользователи, выдача JWT, состояния бронирований и координация саги. HTTP-клиент поддерживает Retry/Timeout/Circuit Breaker. Обработчик восстановления повторяет компенсации по bookingId, включая потерянный ответ с неизвестным номером. Настройки, discovery и политика вызовов разделены в клиентском пакете.

Сборка, запуск, API и параметры описаны в [корневом README](../README.md).
